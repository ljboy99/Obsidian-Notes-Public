DNS translates hostnames (like domain names) to IP Addresses. 

This makes it so that a user can type www.google.com and the request will be resolved to navigate to 216.58.207.206.

DNS essentially keeps and tracks a table with information for where domain names are supposed to resolve to, so that the DNS server can point the browser in the right direction.
