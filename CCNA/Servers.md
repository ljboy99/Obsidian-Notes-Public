Servers are computers or systems which usually run 24/7 to distribute functions or information to other programs or devices. The latter programs/devices would be clients of the server. 

Servers can be built to distribute:
- files
- mail
- data
- game data 
- or web pages

Most servers have a CPU, memory and storage with a server OS. They tend to have some sort of connectivity to other devices.

Servers generally use a server OS or application to actively listen for requests from clients

Client-Server Request-Response Model:
1. Client needs data or a function, asks the server
2. Server sees request, processes it, returns data 

Types of servers:
- Application Server: Allows apps to run via a web browser
- Catalog Server: Holds an index of information for a large distributed network. Ex, this may hold credentials for someone to log in.
- Communication Server: Helps an endpoint find other endpoints to communicate with. May sometimes contain a directory of endpoints. 
- Computing Server: gives clients access to a remote base of processing power via its own CPU and RAM. 
- Database Server: Maintains a collection of data with predefined properties for access by client programs. 
- File Server:  Shares files and/or folders over a network.
