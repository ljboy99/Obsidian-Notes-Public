Sometimes, when data is sent, the IP addresses need to be translated to another IP.

Network Address Translation translates one IP address to another. 

This is needed because an individual network my utilize several private IP addresses, but when it sends info out to the internet, that data needs to come from the internet facing public IP address, usually assigned to the networks router. 

This helps private IP address be able to be reused in any number of different networks. 

In the end, the use of private IPs allows for re-usability for each different network and significantly slows the consumption of public, non-reusable, IP addresses.
