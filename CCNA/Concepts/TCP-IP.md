Transmission Control Protocol / Internet Protocol

TCP/IP is the foundational group of protocols which enable devices to communicate across the internet. it is a vendor neutral protocol for networking equipment. It allows for equipment from different vendors to be used easily with eachother in a network, as opposed to engineers having to figure out how to make the different proprietary interfaces work together. 

The **TCP/IP [[Application Layer]]** defines the services that applications need to run and serves as a bridge between your software and the network it operates on.

The **[[Transport Layer]]** ensures that data is sent in order, end-to-end, between multiple devices. It preserves the integrity of the data being moved even whe multiple processes are occurring at the same time. 

The **[[Network Layer]]** is the medium in which messages travel across a network to get from a host IP to a Destination IP. This layer relies on addressing, encapsulation and rebuilding the data that was sent from the host on the destination end.
